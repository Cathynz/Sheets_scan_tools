   # Sheets Scan Tools

This repository contains Python tools for scanning, extracting, and processing sheet or drawing-related data.

## Overview

These scripts are used to support document scanning, data extraction, text matching, geolocation lookup, and data handling workflows.

The tools may include:
- PDF or sheet scanning
- text extraction and cleaning
- fuzzy matching of project or drawing information
- geolocation or address lookup
- CSV or Excel output
- optional simple desktop interface using Tkinter

## Main Python Libraries Used

### Built-in modules
These come with Python and do not need separate installation:
- `urllib.parse` (for functions such as `quote`)
- `datetime`

### External packages
These usually need to be installed:
- `pandas`
- `thefuzz`
- `geopy`

### Optional / environment-dependent
- `tkinter`  
  Usually included with standard Python on Windows. If not available, Python may need to be reinstalled with Tk support.
